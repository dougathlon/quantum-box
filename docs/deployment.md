# Deployment and public-repository contract

The stable public application is
<https://dougathlon.github.io/quantum-box/>. Build query parameters identify a
release for review; they do not create a second deployment address.

## Public branch

`main` in `dougathlon/quantum-box` is both the collaborator-facing source and
the Pages release branch. The deployment workflow performs a frozen install,
source scan, full local gate, Linux Chromium journeys, production build, and
Pages upload. `dist/` is generated by the workflow and is not committed.

## Release preparation

Internal development history and acquisition work remain private. Prepare a
release in a fresh clone of public `main`, then overlay only the reviewed
release tree. Before commit, exclude:

- credentials, `.env` files, provider caches, and operator state;
- `.moth-cache`, raw acquisition material, and machine-local paths;
- internal worktrees, private logs, unpromoted mockups, and QA screenshots;
- retired Enclose and physical Designer/player/room/Workshop production assets;
- source maps, backup files, build output, and unrelated drafts.

Run `pnpm scan:source` in the staging clone. That scan is intentionally stricter
than ordinary local development because the private tree may retain historical
recovery material.

## Release gate

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test:e2e
pnpm scan:source
```

Record exact commands and failures. Playwright collection inside `pnpm check`
does not substitute for `pnpm test:e2e`. If local managed-browser execution is
blocked by host policy, report it and require the Linux workflow plus direct
served-browser evidence; do not relabel collection as execution.

## After push

1. Wait for the Pages workflow attached to the pushed `main` commit.
2. Confirm the deployed document and assets resolve at the stable URL.
3. Hard-refresh and exercise title/start, menu audio, Story, Terminal, Arcade
   trial sheets, saves, scores, controls, and a representative cabinet.
4. Confirm no provider request, source map, private path, or retired asset ships.
5. Distinguish workflow success, direct live execution, and outstanding human
   visual/listening acceptance in the handoff.

The repository intentionally has no project licence. Do not add one as part of
a release unless the maintainer authorizes that separate decision.
